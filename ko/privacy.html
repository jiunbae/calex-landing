개인정보 처리방침

시행일: 2026년 11월 16일

요약: Calex는 온디바이스(로컬) 우선으로 동작하며, 광고를 노출하지 않고, 앱·웹사이트를 넘나드는 추적을 하지 않으며, 개인정보를 판매하지 않습니다. 오디오·전사·요약·할 일은 사용자가 iCloud 동기화를 켜거나 음성 인식(STT) 또는 AI 제공자에게 내용을 보내는 기능을 직접 선택하지 않는 한 기기 안에 머뭅니다.

1. Calex가 기기에 저장하는 것

Calex는 회의 노트 및 하루 리뷰 기능을 제공하기 위해 녹음, 전사, 요약, 결정, 할 일, 대시보드 기록, 앱 설정, 모델 선호, 위젯 상태, 진단 상태 등을 사용자의 기기에 저장할 수 있습니다.

2. 마이크, 녹음, 언제나 듣기

Calex는 사용자가 권한을 허용하고 녹음 또는 언제나 듣기(Always Listen) 세션을 시작한 후에만 마이크를 사용합니다. 앱에서 언제든 듣기를 중단할 수 있으며, 오디오 캡처 중에는 iOS와 macOS의 시스템 마이크 표시가 나타납니다.

로컬 Calex 데이터는 앱 안에서 삭제하거나 기기에서 앱을 삭제하여 제거할 수 있습니다.

3. 선택적 음성·AI 제공자

일부 전사·요약·모델 기능은 사용자가 선택하거나 구성한 음성 인식 또는 대규모 언어 모델 제공자를 필요로 할 수 있습니다. 해당 기능을 사용할 때는 요청한 작업을 완료하기 위해 오디오, 전사 텍스트, 프롬프트, 요약 또는 관련 메타데이터가 해당 제공자에게 직접 전송될 수 있습니다.

이러한 제공자는 각자의 개인정보 처리방침과 계정 약관에 따라 데이터를 처리합니다. Calex는 사용자의 회의 콘텐츠를 저장하는 별도의 서버를 운영하지 않습니다.

4. 캘린더, 알림, 위젯

캘린더 관련 워크플로를 사용하는 경우, Calex는 노트를 일정과 연결하는 데 필요한 캘린더 메타데이터를 읽을 수 있습니다. 알림·위젯 데이터는 기기에서 녹음 상태, 리마인더, 최근 요약을 표시하는 데 사용됩니다.

5. 분석, 광고, 추적

  • Calex는 서드파티 광고 SDK를 사용하지 않습니다.
  • Calex는 다른 회사의 앱·웹사이트를 넘나들며 사용자를 추적하지 않습니다.
  • Calex는 개인정보를 판매하지 않습니다.
  • Calex는 로컬 앱 사용을 위해 별도의 Calex 계정을 요구하지 않습니다.

6. 데이터 공유

Calex는 사용자가 외부 제공자가 필요한 기능을 명시적으로 사용하거나, iCloud 동기화를 켜거나(사용자의 iCloud 계정에 Apple이 저장), 콘텐츠를 직접 내보내기/공유하거나, 법률상 요구되는 경우를 제외하고 개인정보를 제3자와 공유하지 않습니다.

7. 보안

Calex는 앱 샌드박싱과 시스템 권한 요청 등 Apple 기기에서 제공하는 플랫폼 보안 기능을 사용합니다. Calex에 연결하는 외부 음성·AI 제공자의 개인정보 및 보존 설정을 직접 확인하시기 바랍니다.

8. iCloud 동기화 (macOS·iOS)

iCloud 동기화는 선택 기능입니다. 켜면 Calex는 사용자 Apple 계정의 비공개 iCloud 데이터베이스(CloudKit)를 사용해 요약, 할 일, 일정, 결정과 전사 기록의 최신 변경 사항을 사용자의 다른 기기와 주고받습니다. 음성 파일은 동기화하지 않습니다. Calex는 별도의 동기화 서버를 운영하지 않으며, 이 데이터는 Apple의 약관과 개인정보 처리방침에 따라 Apple이 저장합니다.

동기화되는 내용은 항상 전송 중과 Apple 서버에서 암호화됩니다. 여기에 더해 Calex는 동기화 기록의 본문(전사, 요약, 할 일, 일정, 결정)을 CloudKit 암호화 필드에 저장할 수 있으며, iCloud 고급 데이터 보호를 켜면 이 본문은 종단 간 암호화되어 Apple도 키에 접근할 수 없습니다. 암호화 필드는 같은 계정의 모든 기기가 이를 읽을 수 있는 앱 버전으로 24시간 동안 이어서 확인되면 자동으로 쓰기 시작하며, 그 뒤 이전 기록을 차례로 옮깁니다. 다른 기기를 확인할 수 없으면(예: iCloud 키-값 저장소를 쓸 수 없을 때) 일반 필드를 계속 씁니다. iCloud 설정에서 지금 바로 암호화 필드를 쓰도록 고를 수도 있고(다른 기기의 이전 버전 앱은 읽지 못함), 일반 필드로 되돌릴 수도 있습니다. 그 전이나 사용자가 되돌린 경우에는 본문이 일반 필드에 있어 고급 데이터 보호를 켜도 종단 간 암호화되지 않습니다. 지금 어느 방식으로 저장하는지와 옮기는 진행 상황은 iCloud 설정 화면에 표시됩니다. 날짜, 기록 종류, 계정·기기 식별자 같은 동기화 정보는 항상 일반 필드에 남아 종단 간 암호화되지 않습니다.

동기화가 켜져 있으면 다른 기기 녹음 중단 알림, 두 기기 요약 중복 방지, 본문 저장 방식 판단을 위해 이 기기의 이름과 플랫폼, 앱 버전과 지원 기능 버전, 듣기 상태, 녹음 시작·끝 시각, 마지막으로 소리를 받은 시각, 마지막으로 전사를 저장한 시각과 마지막 발화가 끝난 시각을 iCloud 키-값 저장소에 저장합니다. 동기화를 끄면 이 정보를 보내지 않고, 이미 저장된 이 기기의 값을 지웁니다.

기록 보관 기간 설정, 이 기기가 그 설정을 지원한다는 표시(앱 빌드와 갱신 시각), 요약 “따로 보기” 선택은 동기화와 관계없이 같은 저장소로 다른 기기와 공유합니다. 어느 것에도 대화 내용은 들어가지 않습니다.

동기화를 그냥 끄면 이미 iCloud에 올라간 기록은 지워지지 않습니다. 끌 때 iCloud 사본을 함께 삭제할 수 있으며, 기기에 있는 데이터는 그대로 남습니다. 최신 버전 기기는 사본이 삭제된 것을 알면 스스로 동기화를 끕니다. 이전 버전 기기나 동기화를 다시 켠 기기는 자기 기록을 다시 올릴 수 있습니다.

iCloud 동기화와 별개로, 사용자가 만드는 기기 백업(iCloud 백업, Finder·iTunes 백업, Time Machine)에는 전사·요약이 담긴 Calex 기록 데이터베이스가 들어갑니다. 보관한 음성과 성문은 기기 백업에서 제외합니다.

9. 보관 기간

모든 플랜에서 기본적으로 전사는 90일, 요약은 180일이 지나면 기기에서, 그리고 동기화를 켠 기기가 있는 동안 iCloud에서도 자동으로 삭제됩니다. iCloud 사본을 지우지 않은 채 모든 기기에서 동기화를 끄면, iCloud에 남은 기록은 그 사본을 삭제할 때까지 남습니다. 설정에서 이 기간을 바꿀 수 있으며(90일, 180일, 1년, 삭제 안 함), 선택은 같은 Apple 계정의 모든 기기에 적용됩니다. 기간을 줄이면 적용 전에 지워질 기록 수를 먼저 보여 줍니다. 음성 녹음은 음성 보관을 켠 경우에만 기기에 남으며 동기화하지 않습니다.

10. 화자 식별, 연동, 모델 (macOS·iOS)

화자 식별을 위해 목소리를 등록하면 Calex는 먼저 동의를 받고, 성문 데이터를 해당 기기에만 저장하며 동기화하지 않습니다. 설정에서 성문을 삭제하거나 동의를 철회할 수 있고, 철회하면 모두 지워집니다.

사용자가 설정한 웹훅과 연동(Slack, Discord, Telegram, Notion, 일반 웹훅)은 사용자가 구독한 이벤트만 입력한 대상으로 해당 서비스의 약관에 따라 보냅니다. 요약, 할 일, 하루 리포트, 듣기 시작·종료, 원문 전사 같은 이벤트를 고를 수 있습니다. 기본으로 구독된 이벤트는 없으며, 원문 전사는 민감한 정보라는 경고를 먼저 보여 줍니다. 제공자 API 키와 연동 토큰은 Apple 키체인에 저장됩니다.

온디바이스 음성·언어 모델을 고르면 Calex는 Hugging Face, GitHub 또는 Apple이 호스팅하는 에셋 팩에서 모델을 내려받습니다. 이는 사용자 콘텐츠가 아닌 모델 데이터이며, 내려받을 때 녹음이나 전사를 올리지 않습니다.

11. Windows용 Calex

Windows용 Calex는 '언제나 듣기'가 켜져 있을 때만 마이크 소리와, 사용자가 켠 경우 PC의 시스템 소리를 녹음합니다. 음성은 PC 안에서 온디바이스 모델로 전사·요약되며, 오디오와 전사는 Windows 사용자 프로필 안의 앱 전용 데이터 폴더에 로컬로 저장되고 업로드되지 않습니다. Windows용 Calex는 iCloud나 Calex 서버와 동기화하지 않습니다.

사용자가 클라우드 AI 제공자(예: OpenAI, Anthropic, Google Gemini, Azure OpenAI)를 선택하고 명시적으로 동의한 경우에만, 요약에 필요한 전사 텍스트가 해당 제공자의 약관에 따라 전송됩니다. 사용자가 설정한 웹훅은 선택한 이벤트를 입력한 대상으로 전송합니다. 제공자 API 키와 웹훅 비밀값은 Windows 자격 증명 관리자에 저장됩니다.

화자 식별을 위해 목소리를 등록하면 성문 데이터는 해당 PC에만 Windows 데이터 보호로 암호화되어 저장되며, 동의를 철회하면 삭제됩니다. 처음 사용할 때 음성·언어 모델(수 GB)을 GitHub와 Hugging Face에서 내려받으며, 이는 프로그램 코드가 아닌 모델 데이터입니다.

앱을 제거하면 녹음, 전사, 요약, 성문, 내려받은 모델을 포함한 로컬 데이터가 함께 삭제됩니다. 설정 → 시스템 → '모든 로컬 데이터 삭제'로 언제든(다운로드한 모델 포함 선택 가능) 직접 삭제할 수도 있습니다.

12. 변경

본 방침은 Calex의 발전에 따라 갱신될 수 있습니다. 중요한 변경 사항은 새로운 시행일과 함께 이 페이지에 반영됩니다.
